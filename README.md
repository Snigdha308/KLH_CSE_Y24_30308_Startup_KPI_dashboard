## Project Abstract

Startups generate large amounts of data from sales, customers, marketing,
and financial operations. However, analyzing this raw data manually is
difficult and time-consuming.

This project develops a Startup KPI Dashboard that collects, processes,
and visualizes important business metrics such as revenue, customer growth,
churn rate, profit, and expenses.

Python is used for data analysis and preprocessing, while Power BI is used
for visualization. The dashboard provides meaningful insights that help
startups monitor their performance and make data-driven decisions.

## Project Workflow

1. Analyze startup performance using business data.
2. Clean and preprocess raw datasets.
3. Calculate important KPIs for decision-making.
4. Develop an interactive dashboard for performance monitoring.
